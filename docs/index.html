Built for Power Users

Everything you need to build your second brain.

100% Local-First

Your data never leaves your machine. No accounts, no cloud sync lock-in. Just standard `.md` files residing securely on your filesystem.

Hybrid SQLite Engine

Lightning-fast full-text search, graph queries, and tag indexing powered by a dual-write SQLite database that stays perfectly in sync with your files.

Advanced Editor

Built on CodeMirror 6. Features full Vim bindings, real-time Mermaid.js diagrams, KaTeX math rendering, and drag-and-drop asset management.

Built-in SRS

Native Spaced Repetition System (SRS). Turn any Markdown note into a flashcard instantly and review them in a dedicated UI right inside the app.

Git Time Travel

Visual Git history for every note. See exact line changes over time and restore historical versions with a single click.

Smart Trash System

Accidentally delete a note? It goes to a physical `.trash` bin. When permanently deleted, Meditor automatically garbage-collects orphaned image assets.

macOS Gatekeeper Workaround

Because this app is currently open-source and not signed with a paid Apple Developer Certificate, macOS Gatekeeper may block it from opening initially, saying the app "is damaged".

To fix this, simply open your Terminal and run:

xattr -cr /Applications/Meditor.app

Alternatively, you can right-click the app in Finder, hold Option, and select Open.
